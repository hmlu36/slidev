請幫我建立下一週的投影片。

如果有指定詩歌（$ARGUMENTS），執行 `npm run new-week` 並把每個歌名用雙引號帶入；否則執行 `npm run new-week` 使用預設歌單。

注意事項：
1. 執行前先確認每個歌名在 `lyrics/` 有對應檔案；如果找不到，列出名稱相近的檔案問我要用哪一首，不要讓腳本停留在互動詢問。
2. 執行後檢查新建的 `pages/{年份}/YYYYMMDD.md`：每首詩歌引用的檔案都存在，且 `main.md` 的 `src` 已更新到新日期。
3. 完成後回報：新檔案路徑、詩歌清單、`main.md` 狀態，並提醒我可用 `npm run dev` 預覽。
