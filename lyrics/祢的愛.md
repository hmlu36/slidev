# 祢的愛

---

#### [Verse]
# 祢創造宇宙萬物
# 統管一切所有
# 但祢卻關心我的需要
# 瞭解我的感受

---　

# 祢手鋪陳天上雲彩
# 打造永恆國度
# 但這雙手卻甘心為我
# 忍受徹骨釘傷苦痛

---　

#### [Pre Chorus]
# 祢公義審判萬民
# 聖潔光照全地
# 但祢卻一再賜恩典
# 一再施憐憫 給我機會回轉向祢

---

#### [Chorus]
# 祢的愛如此溫柔 超乎我心所想
# 這樣大有能力的主
# 竟捧我在手掌心上

---

# 祢的愛如此深切 我知我無以報答
# 但願倒空我的生命
# 學習祢謙卑的樣式
# 背起我自己的十字架
